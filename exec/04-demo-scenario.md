# 4. 시연 시나리오

등장 역할: **강사**(PC 브라우저, `https://i-eum.site`) · **학습자**(Android 앱) · **촉각 모듈**(Arduino, 블루투스). 시연 전 준비물은 마지막 절.

화면 이름은 코드의 라우트 기준이다 — 웹 `front/apps/web/src/pages/*Page.tsx`, 앱 `front/apps/mobile/src/app/**`.

## 4.1 강사 — 가입·수업 준비 (웹)

| 순서 | 화면 | 조작 | 기대 결과 |
| --- | --- | --- | --- |
| 1 | `https://i-eum.site` → 회원가입 (`SignupPage`) | 아이디·이메일·비밀번호 입력 → 가입 | 인증 메일 안내. 메일의 링크 → `/auth/verify-email` 페이지에서 인증 완료 |
| 2 | 로그인 (`LoginPage`) | 아이디·비밀번호 → 로그인 | 수업 목록으로 이동 |
| 3 | 수업 목록 (`LectureListPage`) | **수업 만들기** 클릭 | 수업 생성 화면 |
| 4 | 수업 생성 (`LectureCreatePage`) | 제목·설명·예정 시각 입력, 문제은행에서 **문제 선택**(단계·학습 요소로 조회, 정답 셀 확인) → 생성 | 목록에 수업 카드. **참여 코드 6자리** 표시 |
| 5 | 수업 목록 | 만든 수업 → **수업 시작** | 라이브 화면 |
| 6 | 라이브 (`LiveLecturePage`) | 브라우저 마이크 허용 → **마이크 켜기** | 학습자에게 강사 음성 송출(OpenVidu). 참여자 목록·현재 문제 영역 표시 |

## 4.2 학습자 — 설치·가입·온보딩 (앱)

| 순서 | 화면 | 조작 | 기대 결과 |
| --- | --- | --- | --- |
| 1 | 폰 브라우저 `https://i-eum.site/app` | APK 다운로드 → 설치 | 최신 버전·배포일 표시 (`latest.json`) |
| 2 | 앱 실행 → 사용 방식 (`onboarding/mode`) | **음성 중심** 또는 **화면 중심** 선택 | 음성 중심: 큰 버튼·TTS 안내 / 화면 중심: 정보 밀도 높은 카드 |
| 3 | 소리와 진동 (`onboarding/accessibility`) | 음성 안내·속도·진동·글자 크기 설정 | 설정이 즉시 낭독으로 반영 |
| 4 | 사용 안내 (`onboarding/guide`) | 안내 듣기 또는 건너뛰기 | 설정에서 다시 볼 수 있음 |
| 5 | 가입 (`auth/sign-up`) | 4단계 입력(아이디 → 비밀번호 → 확인 → 이메일), 아이디 **중복 확인** | "인증 메일을 확인하세요" (`auth/verify-email`) |
| 6 | 로그인 (`auth/sign-in`) | 인증 후 로그인 | 홈 |
| 7 | 홈 (`(tabs)/index`) | — | "홈이에요. OO님, 자음을 배우는 중이에요…" 낭독. 이어서 학습 / 복습 시작 / 수업 참여 / 점자 장치 상태 |

TalkBack을 켜고 2~7을 진행하면 접근성 시연이 된다(모든 버튼에 라벨·힌트, 6점 입력 영역은 탐색 제스처와 충돌하지 않음).

## 4.3 학습자 — 실시간 수업 참여

| 순서 | 화면 | 조작 | 기대 결과 |
| --- | --- | --- | --- |
| 1 | 수업 탭 (`(tabs)/class`) | 강사의 **참여 코드 6자리** 입력 → 참여 | 대기 화면 (`class/waiting`) — "수업이 시작되면 알려 드릴게요" |
| 2 | (강사) 라이브 화면 | 문제 하나를 **현재 문제로 전달** | 학습자 화면이 풀이로 전환 (`class/play`), 강사 음성 수신 중 |
| 3 | 풀이 (`class/play`) | 화면의 **6개 점 영역**을 눌러 정답 셀 입력(누를 때마다 "1번 점" 낭독 + 진동) → **제출** | 채점 (`class/grade`): 정답/오답, 틀리면 **빠진 점·더 누른 점** 낭독 |
| 4 | (강사) | 다음 문제 전달 → 반복 | 강사 화면에 학습자별 제출·정오 실시간 표시 |
| 5 | (강사) | **수업 종료** | 학습자 종료 화면 (`class/end`) |
| 6 | 종료 (`class/end`) | **수업 오답 복습** | 단계별 오답 확인 (`class/review`) → 개인 복습 세션으로 연결 |

연결이 끊기면 `class/disconnected` 화면에서 **다시 연결** → 기존 참여 관계·본인 결과 복원.

## 4.4 학습자 — 개인 학습·맞춤 복습

| 순서 | 화면 | 조작 | 기대 결과 |
| --- | --- | --- | --- |
| 1 | 학습 탭 (`(tabs)/learn`) → 단계 선택 (`learn-themes`) | 열린 단계(자음 → 모음 → 약자 → 단어 → 약어 → 문장) 중 하나 | 세션 안내 (`session/intro`) — 문항 수·조작법 낭독 |
| 2 | 풀이 (`session/play`) | 6점 입력 → 제출 | 채점 (`session/grade`) |
| 3 | 채점 (`session/grade`) | 오답이면 정답 셀·내 입력 비교(누락점 강조) 확인. **촉각으로 확인**(4.5) / 따라 하기 → **다음 문제** | 10문항 반복(5문제 × 2) |
| 4 | 마지막 제출 | — | 분석 중 (`session/analyzing`) → 요약 (`session/summary`): 정답률·약한 학습 요소·현재 숙련도 |
| 5 | 홈 → **복습 시작** | — | 서버가 약한 요소를 골라 출제한 복습 세션 (`mode=review`) |
| 6 | 도구 → 내 실력 (`tools/skills`) | — | 학습 요소별 숙련도 |

앱을 닫았다 열면 진행 중 세션을 이어서 시작한다(홈의 "이어서 학습").

## 4.5 촉각 모듈 (아두이노)

| 순서 | 화면 | 조작 | 기대 결과 |
| --- | --- | --- | --- |
| 0 | 사전 준비 | 모듈 전원 ON(HC-06 LED 깜빡임), 폰 블루투스에서 `HC-06` 페어링(PIN 0713) | — |
| 1 | 설정 탭 → **점자 장치** (`device-error`) | **다시 연결 시도** → "근처 기기" 권한 허용 | "HC-06에 연결했어요", 홈·설정의 장치 상태 **연결됨** |
| 2 | 같은 화면 | **ㄱ 점자 테스트** | 4번 점 솔레노이드가 2초 올라왔다 내려감, "ㄱ, 4번 점을 2초 올렸다 내렸어요" |
| 3 | 개인 학습 채점 (`session/grade`) | 오답 뒤 **촉각으로 확인** | 정답 칸의 점이 모듈에 올라옴("N번째 칸, x번과 y번" 낭독), 2.5초 뒤 내려감 |
| 4 | 도구 → 점자 사전 (`tools/dictionary`) | "사랑" 검색 → **장치로 촉지** | 셀이 한 칸씩 차례로 올라옴 |
| 5 | 설정 → 점자 장치 | **점 모두 내리기** | 전부 내려감 (5초 지나면 펌웨어가 스스로 내림 — 발열 방지) |

Arduino IDE 시리얼 모니터(9600)를 열어 두면 앱이 보낸 `BT RX: ON 4` 같은 명령이 그대로 보여 통신을 증명할 수 있다 (단, 시리얼 터미널 앱 등 다른 기기가 HC-06에 붙어 있으면 안 된다).

## 4.6 음성 비서 "잇다" · 내 목소리

| 순서 | 화면 | 조작 | 기대 결과 |
| --- | --- | --- | --- |
| 1 | 설정 탭 → **잇다 음성 비서** | 켜기 → 마이크 권한 허용 | "잇다를 켰어요. 하이 잇다라고 불러 보세요." 이후 앱이 떠 있는 동안 호출어 대기 |
| 2 | 아무 화면 | **"하이 잇다"** | "네, 잇다예요. 무엇을 도와드릴까요?" |
| 3 | 이어서 | **"학습 페이지로 가줘"** / "설정 열어줘" / "점자 사전 열어줘" / "홈으로 가줘" | 해당 화면으로 이동 + 안내 낭독 |
| 4 | 이어서 (모듈 연결 시) | "하이 잇다" → **"3번 점 올려줘"** / "점 전부 내려줘" | 모듈 동작 + 응답 |
| 5 | 되묻기 | "하이 잇다" → "점 올려줘" → "몇 번 점을 올릴까요?" → **"3번"** | 문맥을 이어 실행 |
| 6 | 설정 → **내 목소리로 답하기** (`voice-clone`) | **녹음 시작** → 화면 문장 읽기(3초 이상, 최대 15초) → **녹음 끝내고 복제하기** | 십여 초 뒤 "목소리를 복제했어요". **테스트 재생**으로 확인 |
| 7 | 이후 잇다 응답 | "하이 잇다" | 복제한 목소리로 답한다(네트워크 필요, 실패 시 시스템 TTS로 폴백) |

## 4.7 시연 전 체크리스트

- 서버: `https://i-eum.site` 로그인 화면, `https://i-eum.site/api/v1/username-availability?username=x` 200, `https://i-eum.site/app`에 최신 APK
- 강사 계정 1개(이메일 인증 완료), 시연용 문제가 문제은행에 등록돼 있고 수업에 연결됨
- 학습자 폰: APK 최신, 인증 완료 계정, Google 앱 한국어 음성 인식·한국어 TTS 설치, 블루투스 ON, HC-06 페어링
- 촉각 모듈: 전원·배선(TB6612 STBY/PWM HIGH), 시리얼 모니터에서 `ON 4` → `OK ON 4` 확인
- 인터넷: 폰은 LTE/Wi-Fi 아무거나(음성 인식·Cartesia는 온라인 필요), 강사 PC는 마이크 권한
- 백업: 발표 직전 로컬 스택(`docker compose up`)도 띄워 두면 서버 장애 시 `adb reverse`로 같은 시연 가능
