---
description: GitLab 이슈 번호로 작업을 시작해 브랜치→구현→검증→커밋→MR 초안까지 진행한다
argument-hint: <이슈 번호>
---

이슈 #$ARGUMENTS 작업을 다음 절차로 진행하라:

1. 이슈 내용 파악 — 사용자에게 이슈 제목과 본문(완료 조건 포함)을 붙여넣어 달라고 요청하라.
2. git-branch 스킬로 브랜치를 만들라 (이름에 이슈 번호 $ARGUMENTS 포함).
3. 완료 조건을 기준으로 구현하라. 구조에 영향 주는 결정이 필요하면 계획을 먼저 제시하고 승인받고, 결과를 바꿀 모호함은 질문하라.
4. /verify와 같은 기준으로 검증을 전부 통과시키라.
5. git-commit 스킬로 커밋하라 (footer에 `Refs #$ARGUMENTS`).
6. push 후 mr-draft 스킬로 MR 타이틀·본문 초안을 출력하라.
