# I:EUM 점자 학습 커리큘럼 V2

> 갱신일: 2026-09-08
> 용도: 단계·자가 진단·반복 학습 구성·추천과 진급 규칙
> 관련 문서: [사용자 Flow](./user-flow.md), [기능 명세](./feature-spec.md) · 기획서는 로컬 별도 참고 자료로 보관한다.

## 1. 단계와 학습 범위

스마트폰을 독립적으로 사용하는 저시력 시각장애인을 대상으로 한다. 단계는 학습 내용 분류이며, 한 번에 완료하는 학습 세션과 다르다.

| 단계 | 이름 | 학습 목적 | 범위 |
| --- | --- | --- | --- |
| L0 | 공통 사용 안내 | 모바일 입력·음성·햅틱·화면 설정과 장치 이용 안내 | MVP, 건너뛰기 가능 |
| L1 | 점 위치 | 점 번호와 위치를 이해하고 식별·입력 | MVP |
| L2 | 점 조합과 입력 | 여러 점을 조합하고 입력·교정 | MVP |
| L3 | 자음·모음 | 한글 자모의 점형 학습 | MVP |
| L4 | 글자 조합 | 자음·모음을 조합한 한 글자 학습 | MVP |
| L5 | 단어 | 여러 글자가 연결된 단어 읽기·입력 | MVP |
| L6 | 약자·약어 | 약자·약어와 적용 규칙 학습 | MVP |
| L7 | 숫자·문장부호 | 후속 교육 범위 | MVP 제외 |
| L8 | 문장 | 후속 교육 범위 | MVP 제외 |

DB에는 L0~L6을 각각 한 행으로 관리한다. L0은 사용 안내로서 개인 세션·기본 문제·사용자의 열린 최고 단계에서 제외한다. L7·L8은 현재 학습에 배정하지 않는다. 문제 유형에 SENTENCE 값이 존재하는 것만으로 L8 학습을 제공하지 않는다. 점역·정답 예시는 콘텐츠 검수를 통과해야 하며 최대 6 Cell을 넘는 문제는 제공하지 않는다.

## 2. 선지형 자가 진단

질문마다 ‘안다 / 모른다’를 선택한다. 처음 모른다고 답한 단계에서 시작하며 그 단계까지 연다.

| 순서 | 질문 | 모른다 | 안다 |
| --- | --- | --- | --- |
| 1 | 점자의 위치를 알고 있습니까? | L1 | 질문 2 |
| 2 | 여러 점을 조합해 점자를 입력할 수 있습니까? | L2 | 질문 3 |
| 3 | 한글 자음과 모음의 점형을 알고 있습니까? | L3 | 질문 4 |
| 4 | 자음과 모음을 조합해 한 글자를 점자로 입력할 수 있습니까? | L4 | 질문 5 |
| 5 | 여러 글자를 연결한 단어를 점자로 읽고 입력할 수 있습니까? | L5 | 질문 6 |
| 6 | 점자의 약자·약어와 그 사용 규칙을 알고 있습니까? | L6 | L1~L6 중 복습할 단계 직접 선택 |

모두 안다고 답하면 열린 최고 단계는 L6이고 이번 학습 단계는 사용자가 선택한 L1~L6이다. 최초 세션을 만들 때 최고 해금 단계와 이번 단계를 함께 전달하고, 유효한 문제 배정과 수준 설정을 한 번에 저장한다. 개별 응답은 서버에 저장하지 않고 BKT 평가에도 사용하지 않는다. 하위 단계를 복습해도 열린 최고 단계는 낮아지지 않는다.

선택 단계에 들어가기 전 L0 안내를 제공한다. 건너뛰기와 설정·도움말에서 다시 보기를 허용하며 확인 여부는 프론트 로컬에 보관한다. 장치 연결은 진입 조건이 아니다.

## 3. 한 번의 학습 구성

| 구간 | 학습 내용 | 평가 문항 수 | 학습 기록 |
| --- | --- | --- | --- |
| 풀이 전 안내 | 조작 방법·학습 목표. 현재 미제출 문항의 정답 점형은 공개하지 않음 | 0 | 서버 풀이·BKT 제외 |
| 첫 번째 풀이 | 현재 단계의 서로 다른 문제 5개를 한 번씩 직접 풀기 | 5 | 배정 위치별 독립 풀이 저장 |
| 반복 풀이 | 같은 문제 5개를 섞어 한 번씩 다시 직접 풀기 | 5 | 이전 시도와 구분해 저장 |
| 제출 후 피드백 | 정오답·점수·Cell 차이·정답 확인, 음성·햅틱·촉지와 따라 하기 | 추가 없음 | 최초 결과 유지. 따라 하기는 BKT 제외 |
| 완료 분석 | 10문항의 요소별 정오답 분석·숙련도 갱신·다음 학습 준비 | 추가 없음 | 완료 세션을 한 번만 분석 반영 |

학습 내용 하나는 문제 하나를 뜻한다. 각 문제는 정확히 두 번 등장하며 같은 문제를 연속 배정하지 않는다. 여러 학습 요소가 한 문제에 연결될 수 있으므로 ‘문제 5개’와 ‘학습 요소 5개’는 다르다. 현재 독립 풀이에서 정답을 안내받지 않고 스스로 답한다면 이전에 그 내용을 학습한 사실만으로 평가에서 제외하지 않는다.

이미 제출한 문항은 기존 정답·결과를 다시 볼 수 있다. 반복 문항은 별도 배정 위치로 제출하며 현재 미제출 문항의 응답에 정답을 넣지 않는다. 따라 하기로 오답을 덮어쓰거나 현재 세션의 문항 수를 자동 증가시키지 않는다.

한 세션은 한 단계에 속한다. 중단하면 기존 배정과 저장된 풀이를 대조해 다음 미제출 문항부터 이어한다. 미제출 입력은 서버에 보관하지 않는다. 유효한 오답도 완료 문항으로 세고, 검증 실패·채점 실패는 세지 않는다. 분석 대기 상태에서는 분석을 재시도한 후 다음 개인 학습을 시작한다. 설명·촉지·피드백 포함 총시간과 피로도를 측정해 필요할 때 학습량을 조정한다.

## 4. 학습 요소와 기본 문제

학습 요소는 JAMO(자모), RULE(적용 규칙), DOT(점 위치·조합)의 대분류와 구체적인 요소 코드로 정의한다. 코드는 유형과 무관하게 전체 고유하다. 반복 연습은 새 요소 정의를 만드는 대신 같은 요소에 대한 풀이 관측을 누적한다. 주·보조 구분이나 관계별 추천 가중치는 두지 않는다.

모든 문제는 하나 이상의 L1~L6 단계 및 독립 평가 가능한 학습 요소와 연결한다. 단계 연결은 어떤 학습에서 출제할 수 있는지, 요소 연결은 무엇을 평가하고 어떤 취약점과 연관되는지를 나타낸다. 하나의 일반 문제는 여러 단계·요소에 연결될 수 있다.

학습 제공 전에 L1~L6 각 단계의 SYSTEM 기본 문제 5개씩, 전체에서 서로 다른 최소 30개를 준비한다. 각 기본 문제는 기준 단계 하나와 기본 순번 1~5, 목표 설명·허용 문제 유형·정답 Cell·하나 이상의 평가 가능한 요소를 갖는다. 기본 순번은 해당 단계에서 고유하며 일반 후보에는 기본 순번이 없다. 등록 버전 전체를 사전 검증하고 하나라도 실패하면 저장 전체를 롤백한다.

실제 문제 문구·정답·요소별 평가 규칙은 콘텐츠 제작 시 검수한다. 이 문서는 30문제의 실제 제작 완료를 뜻하지 않는다. L3 자모의 교육 순서, L4 글자 선정, L5 어휘, L6 약자·약어의 사례와 규칙은 실제 콘텐츠 검수 항목이다.

## 5. 숙련도·추천·진급

### 5.1 숙련도 관측

완료한 개인 학습 세션의 요소별 이진 정오답을 배정 순번대로 BKT_V1에 반영한다. 초기 숙련 확률 0.20, 학습 전이 0.10, 추측 정답 0.20, 실수 오답 0.10을 사용한다. 부분 점수·오류 수·풀이 시간·단순 반복 횟수를 BKT 가중치로 쓰지 않는다. 자세한 수식은 [ERD의 현재 학습 상태](./erd.md#table-user_skill_memory)를 따른다.

| 현재 상태 | 판정 |
| --- | --- |
| 미관측 | 사용자·요소 상태 행 없음 |
| 취약 | 숙련 확률 0 이상 0.70 미만 |
| 학습 중 | 0.70 이상 0.95 미만 |
| 숙련 | 0.95 이상 1 이하 |

두 번 연속 정답의 최초 숙련 확률은 약 0.874이므로 숙련 상태가 아니다. 안내·자가 진단·미완료 세션·LIVE·재전송·조회는 관측을 추가하지 않는다. HLR·SRS는 계산하지 않으며 반감기와 다음 복습 시각은 NULL로 유지한다.

### 5.2 다음 문제 선정

현재 단계에 연결된 유효 문제만 후보로 삼는다. 한 문제에 연결된 요소 중 가장 우선인 상태를 대표로 사용한다.

1. 취약 요소: 숙련 확률이 낮은 순.
2. 미관측 기본 문제: 기본 순번 순.
3. 학습 중 요소.
4. 숙련 요소.

같은 우선순위에서는 개인 FREE 풀이가 없는 문제, 마지막 FREE 풀이가 오래된 문제, problemId 오름차순으로 결정한다. 최대 5개의 서로 다른 후보를 고르고 부족분은 아직 선택하지 않은 기본 문제로 채운다. 후보가 없거나 추천 오류·시간 초과가 발생하면 기본 문제 5개를 제공한다. 유효한 서로 다른 5개를 확보하지 못하면 세션을 만들지 않는다.

규칙 채점·BKT·취약점 추천·기본 문제 대체는 필수 기능이다. AI 후보 생성·내용 검증은 세션과 분리된 사전 보충용 보조 기능이며 실패 후보는 저장하지 않는다.

### 5.3 단계 진급

열린 최고 단계의 세션을 완료·분석한 뒤, 해당 단계의 기본 문제 전체에 연결된 모든 요소가 숙련 확률 0.95 이상이면 다음 단계로 한 단계 진급한다. 미관측 요소가 있으면 진급하지 않는다. 하위 단계 복습과 L6에서는 진급하지 않는다. 숙련 상태·카운터·열린 최고 단계·분석 완료 시각은 함께 반영한다.

## 6. 실시간 수업과 복습 연결

실시간 수업의 문제 수·순서는 강사가 운영한다. 개인 세션의 10문항 분량을 수업에 강제하지 않는다. LIVE 풀이·수업 종료로 BKT를 직접 갱신하지 않는다.

종료 수업에서 본인 LIVE 오답을 열린 단계별로 분류해 복습할 단계를 선택한다. 선택 단계의 오답을 우선 후보로 사용하고 5개 미만이면 일반 추천·기본 문제로 보충한다. 5개를 넘으면 각 문제에서 실제 오답으로 평가된 요소만으로 취약 → 미관측 → 학습 중 → 숙련 순위를 매긴다. 이 경우 미관측 후보는 기본 문제일 필요가 없다. 동률은 FREE 풀이 없음·오래된 풀이·problemId 순이다.

선정한 5개 문제를 두 번씩 푸는 일반 FREE 세션을 만들고 완료 후 BKT를 갱신한다. 자동 생성·기존 세션 덮어쓰기·여러 단계 혼합·별도 복습 유형은 제공하지 않는다. 음성·촉지 장치 상태는 학습 단계나 관측 기준을 바꾸지 않는다.

## 7. 콘텐츠 검수

자가 진단의 모든 분기, 단계별 기본 문제 수·고유성, 문항 반복·연속 중복 금지, 요소 평가 가능성, 진급 경계, 수업 오답 복습의 단계 제한을 검수한다. 새 점역 예시는 공식 규칙과 대조해 검증한 후 콘텐츠로 등록한다. 이전 세부 교재 후보는 보관된 교육안(로컬 V1 별도 참고 자료)을 참고하되 현재 단계 범위·평가 규칙을 기준으로 다시 검수한다.
