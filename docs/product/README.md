# 제품 설계 문서 (입구)

서비스가 **무엇을** 제공하는지 정의한다. **어떻게** 만드는지는 [팀 컨벤션](../conventions/README.md), **어디에** 올리는지는 [인프라 문서](../infra/README.md)에 있다.

| 알고 싶은 것 | 읽을 문서 |
| --- | --- |
| 어떤 기능을 어디까지 제공하는가 (수용 기준·비기능 요구사항) | [feature-spec.md](./feature-spec.md) |
| 요청·응답·권한·오류·멱등 계약 | [api-spec.md](./api-spec.md) |
| 테이블·컬럼·관계와 저장 책임 | [erd.md](./erd.md) |
| 사용자 여정·화면 상태·복구 경로 | [user-flow.md](./user-flow.md) |
| 학습 단계·자가 진단·추천·진급 규칙 | [curriculum.md](./curriculum.md) |

## 이 문서들이 원본이다

기능·API·데이터 구조에 대한 판단이 필요하면 이 폴더를 기준으로 한다. 노션 등 외부 사본과 내용이 어긋나면 이 폴더가 맞다. 변경은 다른 코드와 동일하게 브랜치와 MR로 반영한다.

- 파일명에 버전을 붙이지 않는다. 문서 상단의 갱신일과 git 이력이 버전을 대신한다.
- 구현이 명세와 달라지면 코드가 아니라 **문서를 먼저** 고친다. 명세 변경 없이 계약을 바꾸지 않는다.
- API를 추가·수정할 때는 [API 컨벤션](../conventions/code/api.md)의 공통 규칙을 먼저 확인하고, 개별 계약은 [api-spec.md](./api-spec.md)에 반영한다.

## `images/`

ERD 도식을 둔다. 도식마다 본문 삽입용 PNG와 확대·검색용 SVG를 같은 이름으로 함께 둔다.

| 파일 | 범위 |
| --- | --- |
| `erd-overview.*` | 16개 테이블 전체 관계도 |
| `erd-full.*` | 모든 테이블의 모든 컬럼을 담은 전체 상세도 |
| `erd-accounts.*` | 계정·인증 영역 |
| `erd-lectures.*` | 실시간 수업 영역 |
| `erd-content.*` | 커리큘럼·문제 영역 |
| `erd-learning.*` | 풀이·평가·학습 상태 영역 |

도식은 [erd.md](./erd.md)의 컬럼 표에서 생성하므로, 표를 고치면 도식도 함께 갱신한다. 생성 도구와 실행·재현 조건은 [erd-tools/README.md](./erd-tools/README.md)에 있다.
