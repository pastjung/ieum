# solutions — 해결한 문제의 축적

비자명한 문제를 해결했을 때 그 지식을 남기는 곳이다. 다음 사람(과 다음 AI 세션)이 같은 문제를 다시 풀지 않게 하는 것이 목적이다.

## 기록 규칙

- **검증된 해결책만** 기록한다 — 추측이나 시도 중인 것은 안 된다.
- **한 문서에 문제 하나.** 파일명: `YYYY-MM-DD-주제.md`
- 형식: 증상 → 원인 → 해결 → (있다면) 재발 방지 장치. 짧게, 검색될 키워드를 담아서.
- 한 줄로 요약되는 **금지/필수 규칙**은 여기가 아니라 AGENTS.md나 docs/conventions/로 승격한다. 여기는 배경 설명이 필요한 해결책의 자리다.

## 운영 (회고 루프)

- 주간 회고 안건에 "이번 주 반복된 지적"을 고정한다.
- 같은 지적 2회 → 규칙 문서에 명문화 / 문서화 후에도 반복 → 린터·훅·CI 검사로 승격.
- 이 폴더에 쌓인 해결책이 여럿 같은 주제를 가리키면, 그것도 규칙·검사 승격 후보다.
